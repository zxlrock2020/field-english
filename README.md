# Field English · 出差英语口语小册

为海外公路桥梁项目出差准备的英语口语随身手册（单文件 HTML，离线可用，23 个场景 / 200+ 句 / 10 天训练计划）。

- 在线访问：https://field-english.late2theparty2026.workers.dev
- `public/`：网站内容（首页必须为 `public/index.html`）
- `wrangler.jsonc`：Cloudflare Workers 静态资源部署配置

## 更新方式

1. 修改或替换 `public/index.html`
2. 提交到 `main` 分支
3. 如已连接 GitHub，Cloudflare 会自动重新发布；否则本地运行 `npm run deploy`
